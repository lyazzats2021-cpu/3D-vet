# ВетАнатомия 3D

Веб-тренажёр по строению скелета собаки, коровы и лошади для студентов ветеринарного направления. В атласе доступны 85 костей и групп костей. В учебном режиме — девять вопросов за попытку: поиск структуры на модели, распознавание структуры по выделению и определение отдела скелета. Ответы и итог хранятся в памяти вкладки до окончания сеанса.

## Запуск

Требуются Node.js 20.19+ или 22.12+ и браузер с поддержкой WebGL 2. Из корня проекта выполните:

```sh
npm ci && npm run dev
```

Откройте `http://localhost:5173`. После первой установки достаточно `npm run dev`. Если в облачной среде домашний каталог недоступен для записи, укажите кэш в `/tmp`: `npm ci --cache /tmp/3d-vet-npm && npm run dev`.

- `npm run check` проверяет TypeScript, целостность GLB и соответствие узлов моделям данных и источникам.
- `npm run build` создаёт статический сайт в `dist/`. Для публикации на статическом HTTP-хостинге загрузите папку целиком.
- `npm run preview` запускает локальную проверку сайта после сборки.
- `npm run export:html` создаёт автономный `dist/3d-vet.html` с моделями внутри файла. Его можно открыть в браузере без локального сервера.

## Управление

Перетаскивайте модель мышью или одним пальцем. Колесо мыши и щипок двумя пальцами меняют масштаб. Для сдвига используйте правую кнопку мыши, движение двумя пальцами или Shift со стрелками при фокусе на 3D-области. Стрелки вращают модель. Ракурсы подписаны относительно животного.

В атласе наведите указатель на кость, затем нажмите для открытия карточки. Поиск принимает русские и латинские названия. Выбор в списке фокусирует камеру. Кнопка «Показать отдельно» оставляет выбранную кость или группу. При выборе отдела остальные кости скрываются.

## Как добавить животное или кость

1. Подберите модель с подтверждённой лицензией и сохраните её в `public/models/`. Используйте GLB 2.0 со встроенными буферами и без внешних текстур. В координатах glTF направьте голову по +Z, спину по +Y, левую сторону животного по +X, а подошвы разместите около Y = 0.
2. Каждый доступный элемент или группа должны иметь собственный узел `bone__<id>` с пользовательским свойством `extras.boneId: "<id>"`. Например, `bone__scapula` с `boneId: "scapula"` содержит геометрию обеих лопаток. Группы с `boneId` не вкладываются друг в друга. В Blender включите экспорт пользовательских свойств, чтобы они попали в `extras`.
3. Опишите кость в `src/data/bones.ts` и добавьте её к нужному виду. Для нового животного добавьте файл вида и зарегистрируйте его идентификатор и модель в `src/data/animals.ts`. Проверьте название, отдел, расположение и видовую особенность. Поля для латинского названия и сочленений можно оставить пустыми, если их не удалось подтвердить.
4. Запишите источники геометрии в `sources/model-mapping.json`, а авторов, лицензию и изменения в `sources/SOURCES.md`. Для вопросов отметьте параметром `true` хорошо различимые и проверенные структуры. Для девяти вопросов нужны минимум девять таких структур.
5. Запустите `npm run check`. Откройте модель в браузере и проверьте выбор каждой новой структуры из списка и на модели.

## Ограничения

Геометрия адаптирована из учебного атласа Virginia Tech. Положение костей сохранено, а детализация отдельных поверхностей снижена. Размеры моделей нормированы для просмотра, поэтому сравнивать абсолютные размеры между видами по экрану нельзя. Документированные недостающие части перечислены в [таблице источников](sources/SOURCES.md).
